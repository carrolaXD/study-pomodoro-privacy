Sys is a Windows-based, read-only personal assistant that retrieves and organizes academic information from services the user explicitly authorizes. The data is indexed locally for personal search and reference.

Read-only by design

Sys requests only the permissions needed to provide its features. Current Gmail integration requests gmail.readonly. Google accounts are authorized separately, so each identity can only access information allowed by its own Google permissions.

Local-first

In the current version, synchronized content is stored in SQLite on the user's computer, while OAuth tokens are stored in Windows Credential Manager. This website is informational only: it has no sign-in, forms, analytics or access to the user's data.

The use of information received from Google Workspace APIs adheres to the Google Workspace API User Data and Developer Policy, including its Limited Use requirements.

Questions or data removal

Contact the developer at pedrocarrola2006@gmail.com. Access can also be revoked in the user's Google Account permissions; locally stored copies must be removed separately.
