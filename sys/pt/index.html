A tua informação académica,
num único local privado.

O Sys é uma aplicação pessoal de acesso exclusivamente de leitura, que recolhe e organiza informação académica de serviços autorizados pelo utilizador. Os dados são indexados localmente para consulta e pesquisa.

Como tratamos os dadosTermos de utilização

Mediante autorização explícita, consulta mensagens e metadados para sincronização e pesquisa local. Não envia nem altera emails.

Exclusivamente de leitura

O Sys solicita apenas as permissões necessárias. A integração Gmail atual pede gmail.readonly. Cada conta Google é autorizada separadamente e só pode aceder aos dados permitidos à própria conta.

Dados no teu computador

Na versão atual, o conteúdo sincronizado é guardado numa base SQLite local e os tokens OAuth no Gestor de Credenciais do Windows. Este site é apenas informativo: não tem autenticação, formulários, analítica nem acesso aos dados do utilizador.

A utilização de informação recebida das APIs Google Workspace cumpre a Política de Dados de Utilizadores das APIs Google Workspace, incluindo os requisitos de utilização limitada («Limited Use»).
