# study-pomodoro-privacy - contexto do repositório

A política de privacidade da app **Study Pomodoro**, servida por GitHub Pages em
https://carrolaxd.github.io/study-pomodoro-privacy/. Um único `index.html`, sem
build, sem dependências.

- ⚠️ **Este é o único repositório público do Pedro.** Nada de privado entra
  aqui: sem chaves, sem caminhos locais, sem notas internas.
- 🔴 **A Microsoft Store aponta para este URL.** A página não pode desaparecer
  nem mudar de sítio; se mudar o conteúdo, a data `Last updated` muda com ele.
- 🔴 **Há duas cópias e nenhuma automação entre elas.** A fonte em markdown é o
  `docs/privacy-policy.md` do repo `study-pomodoro` (privado); este `index.html`
  é a versão publicada, escrita à mão. Alterar uma obriga a alterar a outra na
  mesma volta, senão a app promete uma coisa e a página diz outra.
- Estão em sincronia desde 2026-06-23 (mesma data nos dois).
- O que a política diz tem de continuar verdade sobre a app: a conta Google é
  **opcional** e a app funciona offline. Se o comportamento mudar, isto muda
  primeiro.

Contexto do projeto todo: repo `study-pomodoro` (`AGENTS.md`), e a memória em
`Claude Memory/PROJECTS/Pomodoro App/` no vault Obsidian.
